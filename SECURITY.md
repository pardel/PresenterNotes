# Security policy

PresenterNotes runs entirely on-device and does not transmit data to any server. The most likely class of issue is a sandbox / entitlement bug or a parser crash on malformed input.

## Reporting a vulnerability

Please email **hello@pardel.dev** with:

- A short description of the issue.
- Steps to reproduce, ideally with a sample input file.
- The macOS version and PresenterNotes version (Help → About).

We aim to acknowledge reports within 5 working days. There is no bounty programme.

## Supported versions

Only the latest tagged release receives security fixes.
