# Roadmap

This is a public, opinionated roadmap. It is **not** a commitment — it is a map so contributors know where help is welcome.

Vote on items by reacting 👍 to them in the [Roadmap & voting discussion](https://github.com/pardel/PresenterNotes/discussions).

## Next (this quarter)

- Confidence indicator for the speech matcher in the status bar.
- Preference pane for `trailingWordCount`, `rollingWindow`, `minAdvanceInterval`.
- PDF export from edit mode.
- Multi-locale speech recognition (German, French, Spanish to start).
- Cough / single-burst filter to reduce false advances.

## Soon

- iPad companion that mirrors Present mode over the local network.
- Teleprompter scrolling mode (continuous scroll instead of paginated).
- Export to Keynote presenter notes.
- Live audience share link (read-only mirror via a local web server).

## Someday

- Apple Watch as advance / retreat clicker.
- visionOS port.
- Per-slide "improvise risk score" that flags chunks most likely to trip the matcher.
- Per-presenter speech model fine-tuning (when the on-device APIs allow).

## Won't do

- Cloud sync. The on-device-only privacy property is load-bearing.
- Built-in markdown WYSIWYG. The plain-text source is the feature.
- Rich slide rendering / charts / images. Use Keynote for slides and PresenterNotes for notes.
